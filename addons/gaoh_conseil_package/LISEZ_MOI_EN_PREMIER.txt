⚡ INSTALLATION RAPIDE (3 ÉTAPES)
---------------------------------

  1️⃣  INSTALLER LES DÉPENDANCES PYTHON
      
      pip install openpyxl python-dateutil


  2️⃣  DÉCOMPRESSER ET COPIER LE MODULE
      
      unzip gaoh_conseil.zip
      cp -r gaoh_conseil /chemin/vers/odoo/addons/
      sudo systemctl restart odoo


  3️⃣  ACTIVER DANS ODOO
      
      → Connectez-vous à Odoo
      → Paramètres > Activer le mode développeur
      → Apps > Mettre à jour la liste des applications
      → Rechercher "Gaoh Conseil"
      → Installer

🚀 APRÈS INSTALLATION
----------------------
  1. Configurer les droits (Utilisateur/Manager)
  2. Importer les données Excel ou créer manuellement
  3. Former les utilisateurs
  4. Commencer à utiliser !


📥 IMPORT DE DONNÉES
--------------------
Utilisez le fichier : gaoh_conseil_import_exemple.xlsx

  1. Ouvrir le fichier Excel
  2. Modifier avec vos données
  3. Dans Odoo : Gaoh Conseil > Configuration > Import Excel
  4. Sélectionner le type (Investisseurs/Immobilier/Placements)
  5. Choisir le fichier
  6. Importer et consulter le rapport
