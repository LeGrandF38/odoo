🚀 OPTION 2 : MODULE SEUL (INSTALLATION RAPIDE)
═══════════════════════════════════════════════════════════════════════════

  📦 Fichier : gaoh_conseil.zip (21 Ko)

  Si vous voulez juste installer le module rapidement :

  📥 COMMENT FAIRE :
  
    1. Téléchargez : gaoh_conseil.zip
    
    2. Installez les dépendances :
       pip install openpyxl python-dateutil
    
    3. Décompressez dans votre dossier addons :
       unzip gaoh_conseil.zip -d /chemin/vers/odoo/addons/
    
    4. Redémarrez Odoo :
       sudo systemctl restart odoo
    
    5. Dans Odoo :
       Apps > Mettre à jour liste > Chercher "Gaoh Conseil" > Installer


📊 OPTION 3 : FICHIER EXCEL D'EXEMPLE
═══════════════════════════════════════════════════════════════════════════

  📦 Fichier : gaoh_conseil_import_exemple.xlsx (7.6 Ko)

  Pour tester l'import de données :

  📥 COMMENT FAIRE :
  
    1. Téléchargez : gaoh_conseil_import_exemple.xlsx
    
    2. Ouvrez avec Excel/LibreOffice
    
    3. 3 feuilles disponibles :
       • Investisseurs (avec exemple)
       • Investissements Immobiliers (avec exemple)
       • Placements Financiers (avec exemple)
    
    4. Modifiez avec vos données
    
    5. Dans Odoo après installation :
       Gaoh Conseil > Configuration > Import Excel
       > Sélectionner type > Choisir fichier > Importer

                            PREMIERS PAS
═══════════════════════════════════════════════════════════════════════════

  Après installation, dans Odoo :

  1️⃣  Créer votre premier investisseur :
      Gaoh Conseil > Investisseurs > Créer
      Remplir : Nom, Prénom, Email
      Enregistrer

  2️⃣  Ajouter un investissement :
      Depuis la fiche investisseur > Onglet "Investissements"
      Ou : Gaoh Conseil > Investissements > Créer

  3️⃣  Tester l'import Excel :
      Gaoh Conseil > Configuration > Import Excel
      Type : Investisseurs
      Fichier : gaoh_conseil_import_exemple.xlsx
      Importer
